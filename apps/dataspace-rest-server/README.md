# Dataspace REST Server

This app hosts control plane and data plane APIs in a single deployable REST server. It provides a unified runtime for transfer lifecycle endpoints, data access operations, and activity processing flows.

It is intended for integrated environments where both protocol coordination and data delivery services need to run together.

## Installation

```shell
npm install -D @twin.org/dataspace-rest-server
```
